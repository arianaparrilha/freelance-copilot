Typography

The type system used across Fiscal Copilot — including typefaces, scale, weights, and spacing tokens. All values are available as CSS custom properties.

Typefaces
Two typefaces are used. Fjalla One for headings, numbers and highlighted data. Merriweather Sans for body text, captions and helper text.

Type Scale
All font sizes are defined as CSS variables relative to the 15px base set on html. Use these tokens instead of raw values.
TokenPreviewrem~px
--text-2xs Micro label · timestamp .65rem ~9.75px
