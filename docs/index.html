Tokens, componentes e padrões visuais do Fiscal Copilot. Usa esta página como referência antes de criar novos ecrãs ou componentes.

Cores

Todos os valores de cor vêm de tokens CSS. Nunca usa hex diretamente no código — usa sempre a variável correspondente. O sistema usa neutrals com subtom azul-navy, não cinzentos puros.

Tipografia

Três fontes com papéis distintos: corpo de texto, UI/headings e dados numéricos. Manter esta separação é o que dá ao Fiscal Copilot o aspeto de ferramenta financeira precisa.

Sombras

A elevação é comunicada por diferença de cor de fundo — não por sombras em cards. Sombras são reservadas para overlays, modais e dropdowns onde é necessário separar um layer flutuante.

--shadow-md Tooltips

Dark Mode

Formulários

Inputs dentro de .fc herdam os estilos de foco, erro e helper text. O erro substitui o helper text — nunca coexistem. Validação só dispara no submit ou ao sair do campo (blur).

Ex: 123456789
NIF inválido. Deve ter 9 dígitos, sem espaços. Ex: 123456789
.fc wrapper · .field-hint helper · .field-err erro · .invalid em input com erro
Tooltips

Ativam no hover e no focus (acessíveis por teclado via tabindex="0"). Variante .tt-right para quando o tooltip não cabe acima.

Limite IVA Calculado com base em todas as faturas emitidas, conforme o art. 53.º do CIVA. Regime fiscal Regime Simplificado para prestações regulares. Ato Isolado para prestações ocasionais.
.tt · .tt.tt-right · sempre com tabindex="0", role="button", aria-label, role="tooltip" no .tt-body
Modais

Overlay com role="dialog", aria-modal="true" e aria-labelledby apontando para o título. O foco move-se para o primeiro elemento quando o modal abre e retorna ao trigger quando fecha. Escape fecha. Tab fica preso dentro do modal.

.modal-ov overlay · .modal container · .modal-hdr .modal-body .modal-ft
Sidebar Nav

Feedback & Erros

Erros de campo aparecem abaixo do input e substituem o helper text. Erros gerais (backend) aparecem acima dos botões do modal. Nenhum usa alert().
